# Graphify Standard Reference

## Role

Primary codebase knowledge layer when a Graphify knowledge graph exists.

## Mandatory first operation when applicable

Update Graphify before substantive codebase analysis.

## Use

Structure, relationships, dependencies, callers/callees, and impact analysis.

## Verification

Verify important findings against source, tests, or runtime evidence. Inferred/ambiguous relationships are hypotheses.

## Refresh

Refresh after material code changes before relying on graph results again.

## Failure

Never claim Graphify was used or updated unless it actually was.
