# Software Development Profile

- Update Graphify first when a project graph exists.
- Use Graphify for structure, relationships, dependencies, callers/callees, and impact.
- Verify important graph findings against source code.
- Use Context7 for version-sensitive framework/package/API research.
- Use the project's configured unit/integration tests and browser E2E tools.
- Standalone Playwright is the default browser E2E standard in this reusable package unless the project specifies another standard.
- Technology-specific rules belong in adapters.
