# AI Work Standard v5

Universal AI-assisted work standard for software, documents, spreadsheets, presentations, research, data, and mixed deliverables.

## Core

- `CLAUDE.md` — AI-facing project contract.
- `docs/00-project/blueprint.md` — project/system blueprint.
- `docs/00-project/ai-standard/standard.md` — universal process: WHAT + WHEN.
- `docs/00-project/ai-standard/guideline.md` — universal reasoning: WHY + HOW TO THINK.
- `docs/00-project/ai-standard/profiles/` — work-type rules.
- `docs/00-project/ai-standard/adapters/` — stack/tool rules.
- `docs/00-project/ai-standard/references/` — standard tool references.

## Universal workflow

Classify → Discover → Plan → Council → User Approval → Execute → Verify → Evidence → Complete.

## Knowledge/tool policy

Graphify is **primary codebase knowledge when applicable** and must be updated before substantive codebase analysis. Context7 is used for version-sensitive technical research when applicable. EnvKit is used for local environment operations when applicable.

The standard is not tied to Laravel, Filament, PHP, Claude, or any single AI provider.
